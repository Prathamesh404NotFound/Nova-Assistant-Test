# Nova Expansion Ideas

These ideas build on capabilities already present in the project:

- **Action receipts:** show the tool, permission, data changed, verification result, and undo option after every external action.
- **Permission profiles:** offer temporary, session, always, and mission-only grants with a single “revoke all” control.
- **Memory review queue:** let Nova surface low-confidence memories for confirmation, correction, expiry, or deletion.
- **Cross-device sync status:** show whether memories, calendar items, tasks, and automations are local-only, synced, or conflicted.
- **Automation debugger:** display trigger matches, condition results, action inputs, retries, and the exact failing step.
- **Agent workbench:** let users compose App Builder, Visual Designer, Code Reviewer, and Mission Runner agents into a named workflow.
- **Coding preview loop:** connect workspace edits to a live preview, deterministic tests, lint output, and an explicit commit/rollback step.
- **Daily briefing:** combine calendar, overdue tasks, unread notifications, due future-self letters, and proactive friction suggestions.
- **Conversation timeline:** make chat, voice, memory saves, tool calls, permissions, and automation runs searchable in Activity.
- **Human-in-the-loop missions:** pause before risky steps, show the exact proposed change, and resume after approval.
